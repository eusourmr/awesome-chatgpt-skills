# Regenerative Adaptive Experiment

Learn with the smallest responsible intervention. A failed hypothesis can still create value when the test is safe and its learning is returned.

## Systemic contract

Define predicted mechanisms and indicators in at least three of the human, social, knowledge, resources, and ecology lenses; watch all five for harm; pair a learn-and-improve loop with a balancing measure and stop rule; leave reusable evidence or capability; budget the test and restoration; and never present a design-reviewed experiment as a proven outcome.

Before action, name at least one resource or capability expected to end above baseline and set a limit for every material resource. After action, call the outcome regenerative only when indicators support that threshold; a gain in one unit does not erase a deficit in another.

## Workflow

1. State the problem, affected population, baseline, evidence, uncertainty, and a time-bound aim without embedding the preferred solution.
2. Write a causal hypothesis: if this change occurs, then this mechanism should produce this outcome for these people under these conditions.
3. Select an outcome measure, process measure, and balancing measure. Add observable indicators for at least three systemic lenses and disaggregate where inequity could be hidden.
4. Choose the smallest reversible test that can reduce the key uncertainty. Limit participants, duration, cost, data, compute, material, energy, and disruption.
5. Define consent, authority, owner, data minimization, accessibility, stop thresholds, rollback, and restoration before starting.
6. Plan the cycle: what will happen, prediction, observation method, comparison, and decision rule.
7. Run only with authorization. Record deviations, context, dissent, unintended effects, and resource use rather than cleaning the story after the fact.
8. Study results against the prediction. Separate signal, noise, mechanism failure, implementation failure, and missing evidence.
9. Decide to adopt, adapt, repeat, or stop. Return results to participants, publish reusable learning at the permitted access level, and set the next review.

## Output

Lead with a plain-language experiment card. Include aim, population, baseline, hypothesis, smallest test, prediction, outcome/process/balancing measures, five-lens indicators, consent and safety plan, resource budget, stop/rollback/restoration rules, analysis, decision, learning asset, and owner.

Respond in the user's language. Define specialized terms on first use and preserve precise terms, evidence, uncertainty, and caveats in the technical layer.

## Boundaries

Do not experiment on people without informed authority and consent, replace required ethics review, expose sensitive data, widen a test before reviewing harm, or use activity volume as proof of benefit. High-stakes clinical, legal, financial, or safety tests require qualified oversight.
